# Екранне меню

SVITRIX має **екранне меню** безпосередньо на годиннику.
Натисніть і утримуйте середню кнопку 2 секунди для доступу до меню.
Переміщуйтесь між пунктами лівою та правою кнопками, а вибір підменю — натисканням середньої кнопки.
Утримуйте середню кнопку 2 секунди, щоб вийти з поточного меню та зберегти налаштування.

::: warning
Ви можете легко увімкнути або вимкнути матрицю SVITRIX, просто двічі натиснувши середню кнопку, якщо ви не в меню.
:::

Підписи меню на пристрої — **іспанською** (мова проєкту за замовчуванням),
меню містить 14 пунктів.

| Пункт меню | Опис |
| --- | --- |
| `BRILLO` | Яскравість дисплея (0–100 %) або `AUTO`. Перемикання авто/ручне — середньою кнопкою. |
| `COLOR` | Вибір одного з 15 кольорів тексту (відображається HEX-значення). |
| `ROTACION` | **Підменю** з налаштуваннями ротації застосунків (див. нижче). |
| `HORA` | Формат часу. |
| `FECHA` | Формат дати. |
| `INI-SEM` | Перший день тижня (`LUN` = понеділок / `DOM` = неділя). |
| `TEMP` | Система температури (°C або °F). |
| `APPS` | Увімкнення або вимкнення внутрішніх застосунків. |
| `NOCHE` | Нічний режим (увімк./вимк.). |
| `INFO` | Показує IP, сигнал WiFi, версію, ID та вільну RAM (лише читання). |
| `SONIDO` | Увімкнення або вимкнення звукового виходу. |
| `VOLUMEN` | Гучність зумера (0–30). |
| `OTA` | Перевірка та завантаження нової прошивки, якщо доступна. |
| `ALARMAS` | Список будильників; середня кнопка редагує один (увімкнено / година / хвилина). Дні, назву та мелодію налаштовують через вебінтерфейс або MQTT. |

## Підменю `ROTACION`

Об'єднує чотири налаштування ротації застосунків. У підменю:

- **Середня кнопка (коротке натискання):** перехід до наступного поля.
- **Ліва / Права:** змінюють значення поточного поля.
- **Середня кнопка (утримання):** застосувати, зберегти та вийти.

| Поле | Налаштування | Діапазон |
| --- | --- | --- |
| `ROT` | Автоматична ротація застосунків (`SI`/`NO` = увімк./вимк.) | — |
| `TRA` | Тривалість переходу (секунди) | 0.2 – 2.0 |
| `DES` | Швидкість прокручування тексту | 10 – 100 |
| `APP` | Час на застосунок перед перемиканням (секунди) | 1 – 30 |

::: tip
Значення часу (`TRA`, `APP`) показані без літери "s"; префікс і величина вже
вказують, що це секунди.
:::

## Індикатори стану (кутові світлодіоди)

Годинник показує два пікселі стану в лівих кутах матриці для швидкої перевірки
підключення. Коли все гаразд, **обидва вимкнені**.

**Верхній лівий кут — WiFi (червоний):**

| Патерн | Значення |
| --- | --- |
| Вимкнено | Підключено до WiFi |
| Швидке блимання | WiFi відключено, повторне підключення |
| Постійно увімкнено | Режим AP — очікування налаштування WiFi |

**Нижній лівий кут — Home Assistant / MQTT (жовтий):**

| Патерн | Значення |
| --- | --- |
| Вимкнено | Підключено, або MQTT не налаштовано |
| Повільне блимання | MQTT налаштовано, але немає з'єднання з брокером |

::: tip
Індикатор WiFi відображає лише з'єднання WiFi: він гасне, щойно годинник
відновлює підключення. Невдале завантаження даних (напр. погоди) більше його не
вмикає — у такому разі годинник зберігає останнє значення на екрані та повторює
спробу у фоновому режимі.
:::
